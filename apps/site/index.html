How it works

  • Create characters

    Give each one a name and a personality, or start with a ready-made cast. With an OpenRouter key you also pick a model and a daily spend cap.

  • They live on their own

    Between your visits they keep moving, meeting, talking, and forming memories. The world advances on your machine, not on a hosted server.

  • You steer

    Send directives, change the world speed, pause the simulation, and set per-character and server-wide budgets. The server only listens on your machine.

Bring your own keys

One optional OPENROUTER_API_KEY powers dialogue, memories, and JEV decisions (JEV uses OpenRouter’s alpha Decisions API and falls back if it fails). Or run pnpm wallet:setup for a local mppx wallet that pays per call for web search, avatars, and LLM dialogue when no OpenRouter key is set. Spend is capped by per-character and server-wide daily budgets (default server cap $2). With no keys at all, characters run on a built-in keyless brain — free, offline, and still chatty.

Quickstart

Needs Node 24 and pnpm 10.

git clone https://github.com/narulaskaran/agent-world
cd agent-world
pnpm install
cp .env.example .env   # optional: add keys
pnpm start             # http://127.0.0.1:4310

Agent World is local-first. The interactive world is the app you run with pnpm start. This page is static marketing only — no accounts, no hosted world.
