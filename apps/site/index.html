How it works

  1. 1

    Create characters

    Name them and write a personality, or start with the ready-made cast.

  2. 2

    They live on their own

    They keep moving, talking, and forming memories while you are away. Everything runs on your machine.

  3. 3

    You steer

    Send directives, change the world speed, pause it, and set per-character and server-wide budgets.

Bring your own keys

Daily budgets cap spend per character and server-wide (default server cap $2).

  • No keys

    Nothing to set up

    Characters run on a built-in brain. Free, offline, never touches the cost ledger.

  • OpenRouter

    OPENROUTER_API_KEY

    Powers dialogue, memories, and JEV decisions (OpenRouter’s alpha Decisions API). Falls back to the built-in brain if it fails.

  • Local wallet

    pnpm wallet:setup

    A local mppx wallet pays per call for web search, avatars, and dialogue when no OpenRouter key is set.

Quickstart

Needs Node 24 and pnpm 10.

git clone https://github.com/narulaskaran/agent-world
cd agent-world
pnpm install
cp .env.example .env   # optional: add keys
pnpm start             # http://127.0.0.1:4310

Local-first. This page is static; the world is the app you run.
