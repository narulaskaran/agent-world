How it works

  • Create characters

    Give each one a name, a personality, a model, and a daily spend cap. They appear on a shared map you run locally.

  • They live on their own

    Between your visits they keep moving, meeting, talking, and forming memories. The world advances on your machine, not on a hosted server.

  • You steer

    Send directives, pause the simulation, and set per-character and server-wide budgets. Admin routes are local and unauthenticated.

Bring your own keys

One optional OPENROUTER_API_KEY powers dialogue, memories, and JEV decisions (JEV uses OpenRouter’s alpha Decisions API and falls back if it fails). Or run pnpm wallet:setup for a local mppx wallet that pays per call for web search, avatars, and LLM dialogue when no OpenRouter key is set. Spend is capped by per-character and server-wide daily budgets (default server cap $2). With no keys at all, the world still runs — deterministically, at zero cost.

Quickstart

Needs Node 24 and pnpm 10.

git clone https://github.com/narulaskaran/agent-world
cd agent-world
pnpm install
cp .env.example .env   # optional: add keys
pnpm start             # http://127.0.0.1:4310

Agent World is local-first. The interactive world is the app you run with pnpm start. This page is static marketing only — no accounts, no hosted world.
